# RUMI

*Roots Under My Ideas.*

**Know where everything you know comes from.**

RUMI is a knowledge keeper. It reads what you collect, ties every note to where it came from, connects what belongs together, and answers with the passages behind it. Your knowledge stays plain Markdown in a Git repository you own, and RUMI runs on your own machine.
